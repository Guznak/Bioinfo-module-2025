# Bioinformatics module: AVA training and the Cronus mission

Backup of the student material, winter 2026. The main download is on Seafile.

## Get everything ready

1. Open the release **course-2026**:
   https://github.com/Guznak/Bioinfo-module-2025/releases/tag/course-2026
2. Download the ZIPs you need. They include the data:
   - Day 1: **AVA_training.zip**, **single_cell_workshop.zip**
   - Day 2: **cronus_mission.zip**
   - Both days: **Rlib.zip** (the R package library)
3. Extract all of them into one folder **alien-lecture** in your Documents folder:

   ```text
   Documents/alien-lecture/
     Rlib/
     AVA_training/
     single_cell_workshop/
     cronus_mission/
   ```

4. Open the `.Rproj` file in the chapter folder, then the workbook script.

## What is in this repository

| Folder | Contents |
|:--|:--|
| AVA_training | Day 1 training: HTML, Rmd, workbook, catch-up scripts (data in the release) |
| single_cell_workshop | Day 1 single-cell workshop: HTML, Rmd, workbook (data in the release) |
| cronus_mission | Day 2 mission: HTML, Rmd, mission script, transmissions (data in the release) |
| archive_2025 | Material from the 2025 course |
